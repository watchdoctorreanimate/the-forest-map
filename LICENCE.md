## 🧩 About

**The Forest Map** is a comprehensive map overlay for The Forest featuring custom markers, loot tracker, minimap, and coordinate display for Windows.

Based on popular mods like **OpenHack**, **Eclipse Menu**, and **QOLMod**.

---

## ✨ Features

### 🗺️ Map Overlay
- Full map overlay — display the entire island map on screen
- Custom markers — place and label your own points of interest
- Minimap — always-visible minimap with zoom and rotate options
- Coordinate HUD — show player position in real-time

### 🎒 Loot & Resource Tracker
- Loot tracker — highlight nearby items and resources
- Resource ESP — see caves, cannibals, and animals through walls
- Item filter — customize which items to track
- Distance indicator — show distance to tracked objects

### 🛠️ Utility & Config
- Config system — save and load profiles
- Hotkey support — toggle features with a key
- Safe mode — restrict risky features
- Auto-update — check for new versions
